This is a simple and user friendly calculator website developed as a project to practise web development. It allows users to perform basic mathematical calculations through an interactive interface.
FEATURES:
1. Addition
2. Subtraction
3. Multiplicationa
4. Division
5. Interactive calculator buttons
TECHNOLOGIES USED
1. HTML = for creating the structure of calculators.
2. CSS = for styling and designing the interface.
3. JavaScript = for calculator functionality.
